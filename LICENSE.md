## O que a AGPLv3 significa, em resumo

A AGPLv3 é uma licença **copyleft forte**. As permissões e obrigações abaixo são um
resumo para orientação rápida — em caso de conflito, o texto legal oficial prevalece.

### Você pode

- Usar este software para qualquer propósito, inclusive comercial.
- Estudar e modificar o código-fonte.
- Redistribuir cópias, originais ou modificadas.

### Você deve

- **Manter o aviso de copyright e a licença** em qualquer cópia ou trabalho derivado.
- **Disponibilizar o código-fonte** de qualquer versão modificada que você distribua —
  inclusive quando a distribuição acontece só por rodar o software num servidor acessível
  pela rede. **Esta é a diferença central entre AGPL e GPL**: a GPL comum só exige
  liberação de código quando o binário é distribuído; a AGPL fecha essa brecha do modelo
  SaaS — se você modifica este sistema e o oferece como serviço via rede (mesmo sem
  distribuir um binário a ninguém), os usuários desse serviço têm direito ao código-fonte
  correspondente, incluindo suas modificações.
- **Documentar as mudanças** feitas em relação à versão original, com data.
- **Licenciar trabalhos derivados sob a mesma AGPLv3** (ou compatível) — não é possível
  pegar este código, modificá-lo e redistribuí-lo sob uma licença mais restritiva.

- Sublicenciar sob termos mais restritivos.
- Remover os avisos de licença e copyright.
- Responsabilizar os autores por danos — o software é fornecido "como está", sem garantia
  (seção 15 e 16 do texto legal).

### Por que AGPLv3 para este projeto

Este é um sistema oferecido como serviço via rede (SaaS) — o cenário exato que a cláusula
de rede da AGPL foi desenhada para cobrir. A escolha garante que, se o código for
modificado e reoferecido como serviço por terceiros, os usuários desse serviço mantenham o
mesmo direito ao código-fonte que teriam com qualquer outra forma de distribuição.
